## ADDED Requirements

### Requirement: Команда /help отображает список всех доступных команд с описанием
Система SHALL поддерживать актуальный список всех команд бота в команде `/help` с подробным описанием формата вызова и назначения каждой команды.

#### Scenario: Пользователь вызывает /help
- **WHEN** пользователь отправляет `/help`
- **THEN** система SHALL отображать форматированный список всех доступных команд, сгруппированных по категориям, где каждая команда указана в формате `<command> — <описание>`

#### Scenario: Полный список команд
- **WHEN** система формирует список help
- **THEN** SHALL включать команды по категориям:

  **Основные команды:**
  - `/start` — Главное меню
  - `/help` — Помощь
  - `/cancel` — Отмена текущего ввода

  **Счета и портфель:**
  - `/account` — Выбор и управление брокерскими счетами
  - `/portfolio` — Просмотр портфеля: стоимость, позиции, доходность

  **Настройки:**
  - `/settings` — Настройки бота: режим работы (SANDBOX/READONLY/PRODUCTION), API-токены, счета

  **Рыночные данные:**
  - `/price <ticker>` — Текущая цена и статус торгов инструмента (тикер, FIGI или ISIN)
  - `/chart <ticker>` — Свечной график инструмента за 30 дней (периоды: 1ч, 4ч, 1д, 1н)

### Requirement: Каждая новая команда SHALL добавляться в /help при регистрации
Система SHALL требовать обновление команды `/help` при добавлении любой новой команды бота.

#### Scenario: Регистрация новой команды
- **WHEN** разработчик регистрирует новую команду в `MessageHandler` через `commandRegistry.registry()`
- **THEN** разработчик ОБЯЗАН также обновить список команд в `HelpCommand.execute()`, добавив описание новой команды в соответствующую категорию

#### Scenario: /help содержит все зарегистрированные команды
- **WHEN** пользователь вызывает `/help`
- **THEN** система SHALL отображать ТОЛЬКО команды, зарегистрированные в `MessageHandler`, без пропусков и дубликатов

#### Scenario: Каждая категория имеет заголовок
- **WHEN** команды сгруппированы по категориям
- **THEN** КАЖДАЯ категория SHALL иметь жирный заголовок (`<b>Категория</b>`) и команды listed underneath
